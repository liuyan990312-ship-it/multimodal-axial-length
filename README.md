# Multimodal Axial Length Prediction Demo

A static, deidentified web demo of a multimodal axial length prediction interface.

The demo presents:

- Structured clinical inputs.
- Ophthalmic image viewing with heatmap and overlay modes.
- Fused axial length trajectory forecasting.
- Modality and token contribution summaries.

All cases and values are for demonstration only. The repository does not include patient identifiers, raw clinical tables, private files, credentials or API keys. This demo is for research presentation, not clinical use.
