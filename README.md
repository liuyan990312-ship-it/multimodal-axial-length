# Multimodal Axial Length Prediction System

Static GitHub Pages demonstration for a deidentified multimodal axial length forecasting prototype.

This repository contains only the browser-based demo:

- `docs/index.html`
- `docs/styles.css`
- `docs/app.js`
- `docs/assets/logo.jpg`
- `docs/assets/demo_assets/`

No Python server, model artifact, source clinical table, API key, patient directory or local research workspace file is included.

## GitHub Pages

Use the following Pages settings:

- Source: `Deploy from a branch`
- Branch: `main`
- Folder: `/docs`

Expected URL after deployment:

```text
https://liuyan990312-ship-it.github.io/multimodal-axial-length/
```
